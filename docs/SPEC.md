# AI 信号场 · Product Specification

> Version: 1.0
> Date: 2026-05-02
> Status: Draft

---

## Requirement Statement（需求陈述）

AI 信号场是一个面向泛 AI 爱好者的 **全平台 AI 资讯聚合网站**。系统每小时自动从 Twitter/X、微博、公众号、知乎、Hacker News、Reddit 等平台抓取 AI 相关内容，经过 AI 翻译（双语展示：中文翻译 + 可折叠原文）、AI 趋势分析和热词提取后，以深色主题的卡片式布局呈现给用户。

未登录用户每个分类只能查看 3 条预览内容，登录后解锁全部内容。产品为纯浏览型，不包含评论、互动、推送、自定义订阅或付费功能。

---

## Proposed Solution（方案描述）

### 前端
- **Next.js 14+（App Router）** + TypeScript + Tailwind CSS
- 深色主题，三栏布局：左侧统计面板 + 中间内容流 + 右侧趋势/热词
- 6 大分类导航：推文、视频、公众号、播客、洞察、趋势
- 时间维度筛选：今日 / 本周 / 本月
- 内容卡片：作者信息、双语内容（可折叠英文原文）、话题标签、互动数据、原帖链接
- 响应式设计，适配手机/平板/桌面

### 认证
- **NextAuth.js**，支持 3 种登录方式：Google、GitHub、Email（Magic Link）
- 登录门控：未登录用户每分类仅展示 3 条，登录后解锁全部

### 数据层
- **Neon PostgreSQL** + Prisma ORM
- 内容保留 30 天，过期自动清理

### 爬虫 & 数据处理
- **Python 爬虫**（Scrapy），部署在 VM 服务器
- **cron 定时任务**，每小时整点执行
- 抓取流程：爬取各平台 → 去重 → OpenAI API 翻译 → AI 趋势分析/热词提取 → 写入 Neon 数据库

### SEO & 分享
- SSR/SSG 页面 + meta tags（基础 SEO）
- Open Graph 图片 + 分享卡片预览（社交分享优化）

## Design Constraints（设计约束）

1. **内容门控**：未登录用户每分类最多 3 条，超过部分显示模糊/锁定状态，引导登录
2. **双语展示**：中文翻译为主，英文原文可折叠展开
3. **深色主题**：主背景 `#0a0a0b`，卡片 `#15171d`，强调色 `#7cf7bf`（绿）
4. **数据时效**：30 天窗口，过期数据自动归档/删除
5. **无用户生成内容**：纯系统生成内容，无评论/互动功能

---

## Technical Constraints（技术约束）

1. **前端**：Next.js 14+ App Router, TypeScript, Tailwind CSS
2. **认证**：NextAuth.js（Google + GitHub + Email Magic Link）
3. **数据库**：Neon PostgreSQL + Prisma ORM
4. **爬虫**：Python + Scrapy，运行在 VM 服务器（cron 定时）
5. **翻译**：OpenAI API
6. **趋势分析**：LLM 对每日内容做总结 + 提取趋势 + 生成热词
7. **部署**：
   - 前端：Vercel（关联 GitHub 仓库，push 自动部署）
   - 爬虫：VM 服务器 cron 定时任务
8. **内容保留**：30 天，通过 cron job 定期清理

### 平台覆盖
- Twitter/X
- 微博
- 微信公众号
- 知乎
- Hacker News
- Reddit

---

## Non-goals（明确不做的事）

1. ❌ 付费/订阅功能
2. ❌ 评论/互动（点赞、收藏、评论）
3. ❌ 推送通知（邮件/短信/Push）
4. ❌ 自定义订阅（用户不能自选关注话题/作者）
5. ❌ 用户生成内容
6. ❌ PWA / 原生 App
7. ❌ 多语言界面（仅中文界面）

---

## Success Criteria（成功标准）

1. **内容抓取**：每小时成功抓取各平台内容，去重率 > 90%
2. **翻译质量**：中文翻译流畅自然，核心信息无遗漏
3. **页面性能**：首屏加载 < 2s（Lighthouse Performance > 90）
4. **SEO 可见**：Google 可收录主要页面，分享链接有正确的 OG 预览
5. **登录转化**：未登录用户看到门控提示后，> 10% 选择登录
6. **数据时效**：爬虫执行到内容上线的延迟 < 5 分钟

## Testing Strategy（测试策略）

### 单元测试
- 数据处理管道：去重、格式化、翻译结果解析
- 认证门控逻辑：未登录/已登录用户的内容访问权限
- 时间筛选逻辑：今日/本周/本月的数据过滤

### 集成测试
- 爬虫 → 数据库写入 → API 读取 的完整链路
- NextAuth 登录/登出流程
- 30 天数据自动清理 cron job

### E2E 测试
- 未登录用户浏览：确认每分类只显示 3 条，超出部分锁定
- 登录后浏览：确认所有内容可访问
- 分类筛选和时间维度切换
- 响应式布局在手机/平板/桌面的表现

### 手动测试
- 翻译质量抽检（每日随机 5 条）
- 趋势分析/热词准确性评估
- 各平台爬虫稳定性监控
